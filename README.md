# 📋 Implementação de Fila em C

Projeto prático desenvolvido para a disciplina de **Programação 2**.

O objetivo foi implementar a estrutura de dados **Fila (Queue)** em linguagem C, aplicando lógica de programação, manipulação de ponteiros e gerenciamento de memória.

---

## 💡 O que foi feito

- Estrutura baseada no princípio **FIFO** (*First In, First Out* - o primeiro que entra é o primeiro a sair).
- Aplicação de lógica para controle das operações principais:
  - Criação e inicialização da fila
  - Inserção de elementos (Enqueue)
  - Remoção de elementos (Dequeue)
  - Verificação de fila vazia
  - Liberação de memória

---

## 🛠️ Tecnologias & Conceitos Utilizados

- **Linguagem:** C
- **Conceitos:** Lógica de programação, structs, ponteiros e alocação dinâmica de memória.
